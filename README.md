# How Docker works

Interactive single-file explainer of how Docker works on Linux and how it maps to this workstation (Ubuntu 26.04, kernel 7.0.0-42-generic, 61 GiB RAM, RTX 3090, 80 `~/Code` projects, PostgreSQL 18, Ollama, and ComfyUI).

**Live:** https://jacoblbagent.github.io/docker-viz/
**Local:** http://localhost:5212/
**Hub:** https://jacoblbagent.github.io/visualizations/

Single HTML file (`index.html`) plus self-hosted Instrument Sans fonts (`assets/fonts/`). No build step, no external dependencies.
