One shared kernel, optional walls per app

A Docker container is not a virtual machine. It runs directly on your existing Linux kernel, but gives one process its own private folder tree and port.

Shared Kernel

~0.15 s boot

VMs boot a second OS and lock away gigabytes of RAM. Containers are regular Linux processes making direct syscalls to your 7.0.0-42 kernel.
